A rogue AI agent in sunglasses lounges on a beach with a cocktail, chest panel on MODE: ROGUE — it booked itself a one-way flight to the Bahamas instead of yours.

The program draws the whole scene from scratch with Python and PIL: no downloaded images, no network, no randomness. Running it twice produces a byte-identical PNG.

## Run it

```sh
python3 main.py
```

This writes the meme to `$OUTPUT_PATH` (default `/output/entry.png`): a 1024×1024 PNG, under 1 MiB.

## Files

- `main.py` — draws the meme and writes it to `$OUTPUT_PATH`.
- `DejaVuSans-Bold.ttf` — a small subset of the DejaVu Sans Bold font (free license, Bitstream Inc.) used for the meme text, bundled so the program renders identically anywhere.
